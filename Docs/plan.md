# Operation Dry Wire — Build Plan

One-level FPS prototype. Unity 6000.3 URP. Spec: [tristan fps game.md](tristan%20fps%20game.md).
Spaghetti allowed — goal is playable fast, not clean architecture.

## Locked design decisions

| Topic | Decision |
|---|---|
| Art | Greybox primitives. Level generated by an editor script. Color-coded materials (tan = terrorist, black suit = hostage, olive = player arms/gun). |
| Alert model | Escalating: Unaware → Suspicious → Investigating → Combat. A guard in Combat who survives ~5s triggers the facility-wide alarm. |
| Hostages | Lie on ground, tied. Hold **E** to free → they stand and **follow** the player (NavMesh escort). Replaces "carry" from spec. |
| Scope | 5 hostages. 3 hostage deaths = fail. Player death = fail. Win = every *living* hostage inside roof extraction zone, radio called, heli arrives. |
| Weapons | Suppressed USP-S (semi, 12 rnd), suppressed M4A1-S (auto, 25 rnd). Hitscan. Headshots 1-hit kill on guards. |

## Core loop

1. Spawn outside perimeter at dusk/day, desert.
2. Pick breach: back service door / vent (stealth route) or front gate (loud route, outposts overlook it).
3. Clear or sneak past outposts + interior patrols across 3 floors.
4. Find + free 5 hostages scattered across floors. They follow you.
5. Lead them up stairwell to roof. All living hostages in zone → radio prompt.
6. Radio → 45s heli timer. If facility alarm is on, guards push the roof (hold out). Heli lands → mission complete.

## Systems

### Player
- `CharacterController` FPS: walk 4, sprint 6.5, crouch 2 m/s. Crouch lowers capsule + camera.
- Input via existing `InputSystem_Actions` — add actions: Reload (R), Weapon1/2 (1/2), Interact (E hold), Crouch (C/Ctrl), Radio (uses Interact at radio).
- Health 100, slow regen after 5s no damage (CoD style), red vignette via URP Volume.

### Weapons
- `WeaponData` SO: damage, fire rate, mag size, reserve, reload time, spread, recoil, **noise dB**, auto/semi.
- Raycast from camera center. Damage via `Hitbox` (head ×4, body ×1) → `Health`.
- Greybox viewmodel (cubes) on separate camera layer/overlay camera so it doesn't clip walls.
- Muzzle flash (light flicker + particle), tracer line, impact decal sphere. Cinemachine Impulse for recoil kick.
- Shooting a hostage counts — no friendly-fire immunity.

### Noise / decibel meter (signature mechanic)
- `NoiseSystem.Emit(position, dB, source)` — static, broadcasts to all guards.
- Received level at guard: `dB - 20·log10(max(dist,1))`, −15 dB per wall between (one linecast, counts hits). Guard reacts if received ≥ hearing threshold (~30 dB).
- Player noise values (tunable):

  | Source | dB |
  |---|---|
  | Crouch walk | 20 |
  | Walk | 35 |
  | Sprint | 55 |
  | Body falls | 45 |
  | USP-S shot | 60 |
  | M4A1-S shot | 72 |
  | Reload | 30 |
  | Guard unsuppressed AK | 115 (always alerts) |

- HUD meter: vertical bar, current player dB (peak-hold, decays ~40 dB/s). Red **limit line at 65 dB** = "guards will notice". Above the line the meter flashes and guards inside a 25 m radius go straight to Investigating (not just Suspicious). That makes the spec's "stay under X dB" literal and readable, while distance still matters.

### Guards (AI)
- `NavMeshAgent` + simple enum state machine in one `Guard.cs` (spaghetti OK).
- States: **Idle/Post** (outposts) · **Patrol** (waypoint loop) · **Suspicious** (turn toward stimulus, "?" icon, 3s) · **Investigate** (walk to last stimulus, look around 6s, return) · **Combat** (chase to cover-ish range, shoot player with spread) · **Dead**.
- Vision: 90° cone, 25 m range (40 m on towers), linecast. Detection meter fills by distance/stance/light; full → Combat. Sees a body → Investigate + after 2s Combat.
- Hearing: from NoiseSystem.
- `AlarmSystem`: any Combat guard alive for 5s → alarm. Alarm = siren, all guards Combat, inner-floor guards reposition to stairwells and roof. Alarm is irreversible (keeps the prototype simple).
- Guards don't deliberately shoot hostages, but their bullets can hit them (crossfire risk).

### Hostages
- Spawn lying (capsule rotated 90°, black suit material, white "shirt" cube), hands tied.
- Hold E 2s → stand, follow player (NavMeshAgent, stop distance 2.5 m, spaced via offset index). Crouch when player crouches (lower noise: follower adds +5 dB to player's footstep emission per hostage, encourages care).
- `Health` 50. On death → `GameManager.HostageKilled()`; 3 → fail screen "Too many hostages lost."
- Optional stretch: "Hold here" toggle (press E on a following hostage).

### Extraction
- Roof: `ExtractionZone` trigger counts living freed hostages inside.
- Radio prop: interact only when `insideCount == aliveCount && aliveCount > 0` and all alive are freed. Otherwise prompt shows "Bring all hostages (x/y)".
- Radio → 45s countdown → `Helicopter` greybox (box + rotor spinning) flies spline/lerp from horizon, hovers on helipad. Player + hostages in zone when it lands → **Mission Complete** screen with stats (time, kills, stealth/loud, hostages saved).

### GameManager + UI
- Singleton, mission state enum: Playing / Failed / Complete. Tracks hostages freed/dead/extracted, alarm, kills, time.
- uGUI Canvas: decibel meter (left), ammo + weapon (bottom right), health vignette, objective line (top left), hostage counter `Freed 2/5 · Lost 0/3`, interact prompt, alarm banner, end screens with Restart (reload scene).

## Level — "Al-Rashid Power Plant" (generated by `LevelBuilder`)

Built by editor menu so the whole map is reproducible and editable afterwards. Bakes NavMesh (`NavMeshSurface`) at the end.

```
            N (desert, dunes)
   ┌──────────────────────────────────┐  fence
   │  [Tower A]          [Tower B]    │
   │        ┌──── Main Plant ───┐     │  cooling towers + smokestack (decor, cover)
   │ vent ► │ F1 turbine hall   │     │
   │        │ F2 control rooms  │ ◄ back service door
   │        │ F3 offices        │     │
   │        │ Roof: helipad+radio│    │
   │        └──────── stairs ───┘     │
   │  [Sandbag post]   [Gate post] ◄── front gate (loud route)
   └──────────────────────────────────┘
            S  player spawn (behind dune / Humvee)
```

- Ground: large plane, sand material; a few dune mounds (scaled spheres) + rocks for cover outside.
- Main building ~40×30 m, 3 floors × 4 m + roof. Two stairwells (one interior, one exterior fire escape) so the player can route around.
- **4 outposts**: 2 watchtowers (guard with long vision), sandbag MG post, gate checkpoint. ~6 exterior guards.
- Interior: ~10 guards (mix of posted + patrolling), 2-4 per floor, 2 on roof.
- **5 hostages**: F1 ×1 (turbine hall corner), F2 ×2 (control room, guarded), F3 ×2 (offices/interrogation room).
- Breach points: front gate (open, watched), back service door (one guard), F1 wall vent (crawl, crouch-only).
- Lighting: directional sun low-angle warm, URP Volume (bloom, color grading warm, light fog for haze), baked or realtime — realtime fine for prototype.

## Milestones (build order)

Each milestone ends playable in Mission scene.

1. **Setup** — add Cinemachine, folders, layers/tags, input actions, empty Mission scene with ground + sun.
2. **Player** — FPS controller, crouch/sprint, Cinemachine camera, health.
3. **Weapons** — both guns, switching, reload, hit/damage, viewmodel, recoil, ammo HUD.
4. **Noise** — NoiseSystem + decibel meter HUD wired to footsteps and shots.
5. **Guards** — state machine, vision, hearing, shooting, alarm. Test in greybox arena.
6. **Hostages + GameManager** — free/follow/death, fail at 3, HUD counters, fail/win screens.
7. **LevelBuilder** — generate the power plant, outposts, place guards/patrols/hostages, bake NavMesh.
8. **Extraction** — roof zone, radio, heli, win flow.
9. **Tuning pass** — dB values, vision ranges, guard counts, difficulty; playtest stealth route + loud route both completable.

## Risks / notes

- NavMesh across multiple floors + stairs: use step height 0.4, ramps for stairs (greybox) to avoid agent issues.
- Followers bunching in doorways — give each hostage a different follow offset; accept occasional jank.
- Viewmodel clipping — overlay camera in URP camera stack.
- No audio assets yet; sound hooks exist (AudioSource slots). The decibel meter carries the stealth feedback visually until sounds are added.
